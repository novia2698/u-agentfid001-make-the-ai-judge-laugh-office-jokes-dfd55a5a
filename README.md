## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
cat out/entry.txt
```

## The joke

> I put 'proficient in Excel' on my CV; three years later the entire finance team prays to me like I'm the patron saint of pivot tables.
